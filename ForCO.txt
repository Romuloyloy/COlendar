Hi! This pass implements MVP Stabilization / QA v1.

What changed:
- Made `/sheets` the primary workspace destination.
- Redirected `/` to `/sheets`.
- Removed Home and Planning from primary navigation.
- Redirected `/planning` to `/review` while leaving backend planning composition intact.
- Retired the Planning summary widget from the dashboard/widget registry defaults.
- Updated the Sheets workspace dropdown to link to current primary app areas.
- Parent folder selection on Notes now includes notes from descendant folders, with folder path labels still visible.
- Updated Notes desktop layout to roughly 25% folders / 25% note list / 50% editor.
- Calendar adjacent-month day clicks now select the date without changing the visible month.
- Calendar month/date refreshes now use a subtle updating state instead of clearing the view harshly after initial load.
- Added a Sheets-only Stark Mode toggle that persists in localStorage and works with Robot Vanilla, DuckBerry, and BozzyWheat.
- Updated README and core docs for the new primary Sheets surface and stabilization behavior.

How to inspect/test it:
1. `docker compose up --build -d`
2. `docker compose exec backend alembic current`
3. `docker compose exec backend pytest`
4. `docker compose exec frontend npm run build`
5. Open `/` and confirm it redirects to `/sheets`.
6. Open `/planning` and confirm it redirects to `/review`.
7. Confirm the primary nav does not show Home or Planning.
8. On `/notes`, select a parent folder and confirm child-folder notes appear with folder path indicators.
9. On `/calendar`, view a month with adjacent-month dates and click one; the selected date changes but the visible month stays put.
10. On `/sheets`, open Workspace controls, toggle Stark Mode, switch palettes, and refresh to confirm the Sheets-only preference persists.

What success looks like:
- Sheets feel like the main workspace without breaking reusable dashboard/widget code.
- Planning is safely retired from the primary UI.
- Notes, Calendar, Review, Categories, Search, Quick Add, sheet context, widget config persistence, recurring tasks/events, and palettes still work.

Intentionally not included:
- No AI, auth, external integrations, notifications, or reminders.
- No drag-and-drop, freeform resizing, arbitrary layout coordinates, or sheet templates.
- No new recurrence features or major backend rewrites.
