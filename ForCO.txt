Hi! This was a Phase 3 hardening pass for Notes and Folders.

What got fixed:
- The Notes page now has a clearer folder tree.
- You can rename folders from the UI.
- You can archive empty folders from the UI.
- You can select a folder and see notes in that folder.
- API errors are shown more clearly in the frontend.
- Backend tests now cover blank names/titles, missing folders, note moves, note archives, and safe folder archive behavior.

How to test it on Windows:
1. Start Docker Desktop.
2. Open PowerShell in the repo root.
3. Run `docker compose up --build -d`.
4. Run `docker compose exec backend alembic upgrade head`.
5. Run `docker compose exec backend alembic current`.
6. Run `docker compose exec backend pytest`.
7. Optional: run `docker compose exec frontend npm run build`.

What to check:
- Home: http://localhost:3000
- Notes: http://localhost:3000/notes
- Backend health: http://localhost:8000/health
- Database health: http://localhost:8000/health/db

Success looks like:
- You can create a root folder and nested folder.
- You can rename an empty or non-empty folder.
- You can create, edit, move, and archive a note.
- Empty folders can be archived.
- Folders with notes or child folders show a safe error instead of being archived.
- Backend tests pass.

Known limits:
- No rich text editor, tags, backlinks, attachments, search, AI, tasks, calendar, tracker, widgets, or sheets yet.
- Folder archive is intentionally not recursive.
