Hi! This was Phase 7: the basic tracker.

What changed:
- Added a Tracker page at http://localhost:3000/tracker.
- You can add and archive water entries for a selected date.
- You can see the selected date's total water intake.
- You can add and archive activity entries for a selected date.
- Added Tracker API routes under /api/tracker.
- Added a new Alembic migration for water_entries and activity_entries.
- The dashboard now shows real tracker summary data instead of a placeholder.
- README.md now describes the tracker module, API, dashboard integration, and Windows Docker workflow.

How I test it on Windows:
1. Start Docker Desktop.
2. Open PowerShell in the repo root.
3. Run `docker compose up --build -d`.
4. Run `docker compose exec backend alembic upgrade head`.
5. Run `docker compose exec backend alembic current`.
6. Run `docker compose exec backend pytest`.
7. Run `docker compose exec frontend npm run build`.

What success looks like:
- Home: http://localhost:3000 shows tracker totals on the dashboard.
- Tracker works at http://localhost:3000/tracker.
- Notes still works at http://localhost:3000/notes.
- Tasks still works at http://localhost:3000/tasks.
- Calendar still works at http://localhost:3000/calendar.
- Backend health works at http://localhost:8000/health.
- Database health works at http://localhost:8000/health/db.
- Backend tests and frontend build pass.

Known limits:
- Tracker is simple daily water and activity logging only.
- No charts, advanced analytics, wearable integrations, nutrition tracking, or custom tracker builder yet.
- No auth, AI, workers, sheets, widgets, drag-and-drop, reminders, or notifications yet.
