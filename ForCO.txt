Hi! This pass implements Workspace Focus Mode v1 for `/sheets`.

What changed:
- Occupied sheet widgets now show a lightweight Focus action in the tile header.
- Focus opens the selected widget in a centered, enlarged overlay while preserving the sheet layout underneath.
- Focus mode reuses existing frontend data and widget rendering; there are no backend changes or migrations.
- Focus can be closed with the Close button or the Escape key.
- The background sheet is subdued while focus mode is open, and normal background interaction is blocked by the overlay.
- Widget spanning, duplicate widget instances, task category filters, title overrides, palette selection, and Quick Add behavior remain intact.
- No permanent resizing, drag-and-drop, floating windows, persisted focus state, arbitrary `x/y/w/h` layout, or unrelated features were added.

How to inspect/test it:
1. `docker compose up --build -d`
2. `docker compose exec backend alembic upgrade head`
3. `docker compose exec backend alembic current`
4. `docker compose exec backend pytest`
5. `docker compose exec frontend npm run build`
6. Open `/sheets`.
7. Use Focus on Notes, Calendar, Tasks, or Tracker widgets.
8. Confirm the widget opens in a larger centered overlay.
9. Close with the Close button and with Escape.
10. Confirm the underlying sheet layout and widget spans are unchanged.

What success looks like:
- Compact widgets still work in the grid.
- Focus mode gives cramped widgets more readable space without feeling like a separate app window.
- The sheet remains calm and visually consistent.
- Existing `/sheets` controls and persistence continue to work.

Intentionally postponed:
- No permanent resizing.
- No drag-and-drop.
- No floating windows.
- No backend focus persistence.
- No new layout model.
