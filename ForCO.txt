Hi! This pass implements Sheet Chrome Polish v2.

What changed:
- Added outside-click behavior for sheet dropdowns. The unpinned top dropdown and bottom Manage dropdown close when clicking outside; a pinned top dropdown stays open.
- Fixed dropdown entrance animation so the top menu opens from its real centered position without a visible jump.
- Added brief bottom-edge sheet-change feedback with the active sheet name and order, such as `3 / 6`.
- Added Robot Vanilla, DuckBerry, and BozzyWheat palette selection to the top Workspace dropdown beside the Sheets-only Stark Mode control.
- Kept palette and Stark selections persisted in browser `localStorage`.
- Made sheet success notices clear automatically after a short confirmation period.
- Updated README and sheet/UI docs for the polished chrome behavior.

How to inspect/test it:
1. `docker compose up --build -d`
2. `docker compose exec backend pytest`
3. `docker compose exec frontend npm run build`
4. Open `/sheets`, open the top Workspace dropdown, and click outside it. Confirm the unpinned dropdown closes.
5. Pin the top dropdown and click outside it. Confirm it stays open until closed or unpinned.
6. Confirm the dropdown opens directly from the top-center position without jumping across the viewport.
7. Change palettes and toggle Stark Mode from the top dropdown, then refresh and confirm both persist.
8. Change sheets with the edge arrows, keyboard arrows, and sheet selector. Confirm the sheet name and order briefly fade in near the bottom.
9. Open the bottom Manage dropdown and click outside it. Confirm it closes.
10. Save slot configuration and confirm the success message disappears automatically.

What success looks like:
- Sheet chrome feels stable without changing the saved grid or widget model.
- Dropdowns are calm, centered, and predictable.
- Sheet-change and save feedback appear briefly without becoming permanent clutter.
- Sheet ordering, last active sheet persistence, widget configs, spanning, focus mode, Stark Mode, and palettes still work.
- Quick Add, Global Search, notes, tasks, calendar, review, categories, and tracker routes remain intact.

Intentionally not included:
- No calendar week view.
- No drag-and-drop, freeform resizing, arbitrary layout coordinates, new backend models, or migrations.
- No AI, auth, external integrations, notifications, reminders, or unrelated features.
