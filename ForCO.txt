Hi! This added calorie tracking and a simple Planning page.

What changed:
- Tracker now supports calorie entries in addition to water and activity.
- You can add and archive calorie entries for a selected date.
- Tracker summary now includes daily calorie total.
- The dashboard tracker card now shows water, activity, and calories.
- Added a Planning page at http://localhost:3000/planning.
- Planning shows a Daily Plan and a seven-day Weekly Plan composed from Tasks and Calendar.
- Added Planning API routes under /api/planning.
- Added a new Alembic migration for calorie_entries.
- README.md now describes calories, Planning, APIs, and the Windows Docker workflow.

How I test it on Windows:
1. Start Docker Desktop.
2. Open PowerShell in the repo root.
3. Run `docker compose up --build -d`.
4. Run `docker compose exec backend alembic upgrade head`.
5. Run `docker compose exec backend alembic current`.
6. Run `docker compose exec backend pytest`.
7. Run `docker compose exec frontend npm run build`.

What success looks like:
- Home: http://localhost:3000 shows calorie total in the tracker summary.
- Tracker works with calories at http://localhost:3000/tracker.
- Planning works at http://localhost:3000/planning.
- Notes, Tasks, and Calendar still work.
- Backend health works at http://localhost:8000/health.
- Database health works at http://localhost:8000/health/db.
- Backend tests and frontend build pass.

Known limits:
- Calories are simple kcal entries only.
- No macros, food database, barcode scanning, nutrition database, meal planning, charts, or advanced analytics yet.
- Planning is read-only and composes Tasks and Calendar data.
- No auth, AI, workers, sheets, widgets, drag-and-drop, reminders, or notifications yet.
