Hi! This pass implements On-Sheet Customize Mode v1.

What changed:
- Added a bottom-edge Customize entry next to Manage on `/sheets`.
- Customize mode rearranges widgets directly on the sheet instead of opening the full slot editor.
- Widgets use a subtle jiggle while customize mode is active.
- Occupied widgets can be dragged to valid empty slots.
- Valid drop targets highlight during drag.
- Save persists the draft slot layout through the existing sheet slot update API.
- Revert restores the last saved slot layout and exits customize mode.
- Existing Customize slots remains available for adding widgets, changing sizes, and editing widget configuration.
- Updated README, Sheets Vision, and UX Guidelines for the new on-sheet behavior.

How to inspect/test it:
1. `docker compose up --build -d`
2. `docker compose exec backend pytest`
3. `docker compose exec frontend npm run build`
4. Open `http://localhost:3000/sheets`.
5. Hover the bottom edge and click Customize.
6. Confirm widgets subtly jiggle and the Save/Revert controls appear.
7. Drag an occupied widget to an empty valid slot.
8. Confirm occupied slots, covered cells, overlaps, and edge-overflow targets do not accept the drop.
9. Save, refresh, and confirm the moved widget persists.
10. Re-enter Customize, move a widget, then Revert and confirm the saved layout returns.

What success looks like:
- Rearranging can happen directly on the sheet.
- Movement remains controlled and limited to empty valid slots.
- Widget spans and per-slot config survive moves.
- The fixed 4x2 grid and existing persistence model remain intact.

Intentionally not included:
- No swapping.
- No invalid-slot drops.
- No freeform layout.
- No arbitrary `x/y/w/h` placement.
- No new resizing rules.
- No dashboard drag-and-drop.
- No sheet templates, AI, auth, migrations, or backend widget model changes.
