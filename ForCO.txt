Hi! This pass implements QoL Utility Update v2.

What changed:
- Categories are now shared across one-time tasks, recurring tasks, notes, and calendar events.
- Notes can be created, edited, filtered, and viewed with an optional shared category.
- Calendar events can be created, edited, and displayed with an optional shared category.
- Calendar events now support weekly, bi-weekly, and monthly-by-day recurrence with an optional recurrence end date.
- Calendar, dashboard, and planning date views project recurring calendar event occurrences.
- Quick Add can assign note/event categories and create recurring calendar events.
- Empty sheet slots now use primary click for slot/widget editing and no longer show a Quick Add button.
- The Planning summary widget is removed from sheet defaults, sheet slot validation, and the sheet widget library.
- Recent Notes and Upcoming Events sheet widgets can be filtered by shared category.
- Tracker entries remain outside shared categories.

How to inspect/test it:
1. `docker compose up --build -d`
2. `docker compose exec backend alembic upgrade head`
3. `docker compose exec backend alembic current`
4. `docker compose exec backend pytest`
5. `docker compose exec frontend npm run build`
6. Open `/notes` and confirm category assignment/filtering.
7. Open `/calendar` and confirm category assignment plus recurring weekly, bi-weekly, and monthly events.
8. Open `/sheets` and confirm an empty slot opens the slot editor and has no Quick Add button.
9. Confirm the sheet widget library has no Planning summary widget.
10. Add Recent Notes and Upcoming Events widgets and confirm their category filters work.

What success looks like:
- Shared categories feel consistent across tasks, notes, and calendar events.
- Recurring calendar events appear on the right dates in Calendar, Dashboard, and Planning.
- Empty sheet slots no longer expose Quick Add.
- Notes and calendar sheet widgets can be scoped to a selected shared category.
- Existing task recurrence, widget spanning, focus mode, palette selection, and tracker behavior continue to work.

Intentionally not included:
- No drag-and-drop.
- No freeform resizing.
- No arbitrary `x/y/w/h` layout.
- No tracker categories.
- No recurrence exceptions.
- No external calendar sync, reminders, invitations, or notifications.
