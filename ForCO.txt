Hi! This pass implements Reliability + Data Safety Pack v1 and moves the backend server to port 8018.

What changed:
- Backend now listens on port `8018`, and Docker Compose/frontend defaults point to `http://localhost:8018`.
- Added backup-style export endpoints under `/api/export`, including full export plus notes, tasks, calendar, tracker, categories, and sheets exports.
- Full export includes metadata, categories, folders, notes, one-time tasks, recurring tasks, task completions, calendar events, tracker entries, sheets, sheet slots, and dashboard widget preferences.
- Exports include archived records for backup completeness.
- Added `/settings` with full/module JSON download buttons, backend/database diagnostics, active palette/Stark state, local-first data safety notes, and known limitations.
- Linked Settings from normal navigation and the sheet Workspace dropdown.
- Added `docs/MILESTONE_V0_1_ALPHA.md` and `docs/KNOWN_LIMITATIONS.md`.
- Updated README and master context for v0.1 alpha, export/backup, diagnostics, and local data safety.

How to inspect/test it:
1. `docker compose up --build -d`
2. `docker compose exec backend pytest`
3. `docker compose exec frontend npm run build`
4. Open `http://localhost:3000/settings`.
5. Confirm diagnostics show backend/database status when the stack is running.
6. Download the full JSON export and confirm the filename includes a timestamp.
7. Download module exports for notes/tasks/calendar/tracker/categories/sheets.
8. Check `http://localhost:8018/health` and `http://localhost:8018/health/db`.
9. Confirm normal routes still work: `/`, `/sheets`, `/notes`, `/tasks`, `/calendar`, `/tracker`, `/review`, `/search`, `/categories`.

What success looks like:
- The app has a clear v0.1 local alpha safety story.
- Exports are readable JSON and include archived records.
- The Settings page gives practical backup and diagnostics utility without becoming a huge settings system.
- No new tables or migrations are added.

Intentionally not included:
- No import/restore.
- No cloud backup.
- No auth, AI, external integrations, notifications, reminders, drag-and-drop, sheet templates, or new recurrence features.
