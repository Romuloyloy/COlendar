Hi! Phase 2 added the database and migration foundation.

What changed:
- SQLAlchemy now has a clean shared Base, timestamp mixin, engine, session factory, and DB connection helper.
- Alembic is configured for migrations and uses the same DATABASE_URL settings as the backend.
- There is an initial empty migration, on purpose, so the database can be stamped without adding feature tables yet.
- A couple of small backend tests were added.

How to test it on Windows:
1. Start Docker Desktop.
2. Open PowerShell in the repo root.
3. Run `docker compose up --build`.
4. In a second PowerShell window, run `docker compose exec backend alembic upgrade head`.
5. Run `docker compose exec backend pytest`.

What to check in the browser:
- Frontend: http://localhost:3000
- Backend health: http://localhost:8000/health
- Database health: http://localhost:8000/health/db

Success looks like:
- The frontend still loads.
- /health says the backend is ok.
- /health/db says the database is connected.
- Alembic applies the migration without errors.
- Pytest passes.
