Hi! This added Global Quick Add.

What changed:
- Added a global Quick Add button in the app navigation.
- Quick Add is available from Dashboard, Notes, Tasks, Calendar, Planning, and Tracker.
- `Ctrl+K` also opens Quick Add on Windows.
- Quick Add can create daily tasks, notes, calendar events, water entries, activity entries, and calorie entries.
- It reuses the existing module APIs and adds no new backend routes, tables, or migrations.
- The current page refreshes its existing data after a successful Quick Add create.
- README.md now documents Quick Add, supported item types, APIs used, limitations, and Windows PowerShell commands.

What success looks like:
- You can open Quick Add from the top navigation.
- You can create each supported item type from the same panel.
- Created items show up in the existing pages and dashboard summaries after the current data refresh.
- Notes created through Quick Add are saved without a folder.

How to test it on Windows:
1. Start Docker Desktop.
2. Open PowerShell in the repo root.
3. Run `docker compose up --build -d`.
4. Run `docker compose exec backend alembic upgrade head`.
5. Run `docker compose exec backend alembic current`.
6. Run `docker compose exec backend pytest`.
7. Run `docker compose exec frontend npm run build`.

What success looks like:
- Home: http://localhost:3000 shows calorie total in the tracker summary.
- Tracker works with calories at http://localhost:3000/tracker.
- Planning works at http://localhost:3000/planning.
- Notes, Tasks, and Calendar still work.
- Backend health works at http://localhost:8000/health.
- Database health works at http://localhost:8000/health/db.
- Backend tests and frontend build pass.

Known limits:
- Quick Add is practical quick-create, not a full command palette.
- No folder picker for Quick Add notes yet.
- No auth, AI, widgets, sheets, drag-and-drop, reminders, notifications, or external integrations.
- No advanced recurrence, analytics, or planning automation.

Next recommended phase:
- Add focused usability refinements, such as better Quick Add post-create navigation or a small folder picker for notes, before any formal widget/sheet work.
